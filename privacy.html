Política de privacidad — Comedia Shorts IA

Última actualización: 17 de octubre de 2026

Qué hace la aplicación

Comedia Shorts IA es una herramienta de uso personal que genera videos cortos de comedia y los sube al canal de YouTube de su propio autor mediante la API de datos de YouTube.

Datos de Google a los que accede

La aplicación solicita únicamente el permiso youtube.upload, que le permite subir videos al canal de la cuenta que la autoriza. No lee videos, comentarios, suscriptores, correos ni ningún otro dato de la cuenta de Google.

Cómo se usan y guardan los datos

El token de autorización se guarda de forma cifrada en la configuración privada del propietario (secretos de GitHub Actions) y se usa solo para subir los videos que la propia herramienta produce. No se venden, comparten ni transfieren datos de usuarios de Google a terceros.

Uso de la API de YouTube

Esta aplicación usa los Servicios de la API de YouTube. Al usarla aceptas las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. El uso de la información recibida de las APIs de Google cumple la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Puedes revocar el acceso en cualquier momento desde la configuración de seguridad de tu cuenta de Google.
